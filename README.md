# フェムーン ホームページ 実装一式

制作：スケルトン株式会社

## 中身

```
index.html        トップページ（1ページ完結LP／セルフチェックは実際に動きます）
privacy.html      プライバシーポリシー
tokushoho.html    特定商取引法に基づく表記
assets/style.css  スタイルシート（1枚）
assets/*.jpg      写真16枚（サロン提供分から選定・リサイズ済み）
```

依存ライブラリはありません。JavaScriptもセルフチェック用の素のJSのみ。
**このフォルダをそのままサーバーに置けば動きます。**

## 公開手順（推奨：Cloudflare Pages ／ 無料）

1. お名前.comでドメインを取得（手順書は別途納品済み）
2. GitHubにこのフォルダをpush
3. Cloudflare Pages で「Connect to Git」→ ビルドコマンドなし・出力ディレクトリ `/`
4. Pages の Custom domains でドメインを追加 → 指示されたネームサーバーをお名前.com側に設定
5. SSLは自動で付きます

Vercel / Netlify / エックスサーバー（FTPで丸ごとアップロード）でも同じように動きます。

## 公開前に必ず直す箇所

### 1. 緑の点線〔要確認〕を全部消す
サロンに確認しないと書けない箇所です。`index.html` `privacy.html` `tokushoho.html` を `要確認` で検索してください。

- LINE公式アカウントID／友だち追加URL（`href="#"` のCTA全部）
- Instagramアカウント
- 電話番号
- 回数券 3/5/8/10/12回の価格と有効期限
- 生理中の受け入れ方針
- 産後は何ヶ月から
- デリケートゾーン非接触の最終確認
- キャンセルポリシー
- プライバシーポリシーの制定日・連絡先

### 2. ドメインを差し替える
`index.html` の以下を実際のドメインに置換：

- `<link rel="canonical" href="https://example.com/">`
- `og:image` / `og:url`
- JSON-LD 内の `url` と `image`

### 3. Googleマップ（実装済み・任意で差し替え）
住所検索ベースの埋め込みを実装済みです。APIキー不要でそのまま動きます。
**Googleビジネスプロフィールを登録したら**、埋め込みコードをGBPのものに差し替えると店名つきのピンになります。
GBPは未登録の可能性が高いので、登録から行ってください。福井市大宮でのMEOはホームページより先に効きます。

### 4. LINEリンクを差す
CTAは全部 `href="#"` または `href="#line"` になっています。LINE友だち追加URLに一括置換してください。

## 実装メモ

- **レスポンシブ**：1440 / 900 / 820 / 700 / 600 / 400px でブレイク。スマホは下部に固定CTAバー。
- **セルフチェック**：8問すべて回答すると「はい」の数で3パターンに分岐して結果表示。ライブラリ不使用。
- **SEO**：`HealthAndBeautyBusiness` の JSON-LD を実装済み（住所・営業時間・料金）。titleに地名を含めています（同名の「フェムーン 武蔵浦和店」と競合するため必須）。
- **画像**：全て `loading="lazy"`（ファーストビュー除く）。1枚あたり70KB以下に圧縮済み、合計940KB。
- **フォント**：Zen Old Mincho / Zen Kaku Gothic New / Jost（Google Fonts）。
- **あしらい**：すべてCSS/インラインSVGで実装。外部素材ファイルなし。
  - 罫＋菱形（見出し下）／スラッシュ枠（\ 見出し /）／四隅かぎ括弧（linear-gradient 4枚）／波形の区切り（インラインSVG＋ヘアライン）
  - 参考にした無料ツール：[Get Waves](https://getwaves.io/)、[Haikei](https://haikei.app/)（生成したSVGは自前で書き直して軽量化）
- **アクセシビリティ**：フォーカスリング、`aria-pressed`、alt属性、`prefers-reduced-motion` 対応。
